What blocking does

Blocking a name makes the board read-only for anyone using it, and releases any plate they hold. It is enforced by the page, not by GitHub — the team code is shared, so a blocked person could pick a different name and carry on. Treat it as a firm request, not a lock. To genuinely cut access, rotate the team code in Connection; that signs everyone out.
